# napm Milestone 1: Tauri shell + real npm Shared Library

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Launch napm as a real Tauri app on macOS whose Shared Library tab shows your actual global npm CLIs with real installed-vs-latest status, replacing the prototype's seeded data.

**Architecture:** Native Rust Tauri v2 backend owns all shell calls and exposes a `scan_installed` command via `invoke()`. The rebranded prototype HTML is the frontend, kept verbatim except that the seeded `TOOLS` array is replaced by the command result. The npm version-merge logic is a pure, unit-tested Rust function lifted from `reference/scanner.js`.

**Tech Stack:** Rust (stable, via rustup), Tauri v2, `serde`/`serde_json`, Node 25 + `@tauri-apps/cli`, vanilla HTML/CSS/JS frontend (no bundler, `withGlobalTauri`).

**Scope note:** This is Milestone 1 of the 6 in the spec (`docs/superpowers/specs/2026-05-30-napm-real-app-design.md`). Only the npm source and the Shared Library pane are wired to real data here. brew/pip/npx scans, Transfers execution, Search, and What's New are later milestones with their own plans. In this milestone, status derivation stays in the frontend's existing `statusOf()` (string inequality, identical to `scanner.js`); the Rust job is producing accurate `installed` + `latest`. Pin persistence, real `size`, and the live splash counts are deferred to their milestones.

**Environment facts (verified on this machine 2026-05-30):**
- Rust is NOT installed (`rustc`/`cargo` missing) — Task 1 installs it.
- Node v25.9.0, npm 11.12.1 present. brew, npx, python3/pip3 present.
- `npm ls -g --depth=0 --json` works and returns real tools (e.g. `@anthropic-ai/claude-code` 2.1.158, `@google/gemini-cli` 0.43.0).
- The real project files currently live inside `napm.zip`; the rebranded prototype is at repo-root `napm-prototype.html`.

```rust
use std::collections::BTreeMap;
use std::process::Command;
use serde_json::Value;

/// Merge `npm ls -g --json` (installed) with `npm outdated -g --json` (latest),
/// mirroring reference/scanner.js scanNpm(). BTreeMap keeps output stable/sorted.
pub fn parse_npm(ls_json: &str, outdated_json: &str) -> Vec<InstalledTool> {
    // (installed, latest) per package key
    let mut map: BTreeMap<String, (Option<String>, String)> = BTreeMap::new();

    if let Ok(ls) = serde_json::from_str::<Value>(ls_json) {
        if let Some(deps) = ls.get("dependencies").and_then(|d| d.as_object()) {
            for (pkg, info) in deps {
                if let Some(ver) = info.get("version").and_then(|v| v.as_str()) {
                    map.insert(pkg.clone(), (Some(ver.to_string()), ver.to_string()));
                }
            }
        }
    }

    if let Ok(od) = serde_json::from_str::<Value>(outdated_json) {
        if let Some(obj) = od.as_object() {
            for (pkg, info) in obj {
                let latest = info.get("latest").and_then(|v| v.as_str()).unwrap_or("").to_string();
                let current = info.get("current").and_then(|v| v.as_str()).map(|s| s.to_string());
                let entry = map.entry(pkg.clone()).or_insert((current.clone(), latest.clone()));
                if current.is_some() {
                    entry.0 = current;
                }
                if !latest.is_empty() {
                    entry.1 = latest;
                }
            }
        }
    }

    map.into_iter()
        .map(|(pkg, (installed, latest))| InstalledTool {
            name: pkg.clone(),
            eco: "npm".to_string(),
            pkg,
            installed,
            latest,
            size: String::new(),
            pinned: false,
        })
        .collect()
}

/// Run the real npm commands and merge. `npm outdated` exits non-zero when
/// results exist, so we read stdout regardless of exit status.
pub fn scan_npm() -> Vec<InstalledTool> {
    let ls = run_npm(&["ls", "-g", "--depth=0", "--json"]);
    let outdated = run_npm(&["outdated", "-g", "--json"]);
    parse_npm(&ls, &outdated)
}

fn run_npm(args: &[&str]) -> String {
    Command::new("npm")
        .args(args)
        .output()
        .map(|o| String::from_utf8_lossy(&o.stdout).to_string())
        .unwrap_or_default()
}
```
